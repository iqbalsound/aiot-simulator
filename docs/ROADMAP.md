# Roadmap / known limits (v0.0.1)

- Node-RED flow export for Lab 4 (the built-in dashboard parses the same serial line).
- MQTT: subscribers receive QoS 0; no TLS, no persistent sessions.
- TFLite sizes and MCU timings are modelled estimates (no TensorFlow bundled).
- ML numbers can differ slightly from scikit-learn (native implementations).
- ARM64 packages (Raspberry Pi) and macOS builds.
- Code signing for the Windows installer.
