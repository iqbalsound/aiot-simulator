# Changelog

All notable changes to the AIoT Simulator. Format: [Keep a Changelog](https://keepachangelog.com/).
The release workflow copies the section of the tagged version into the GitHub Release notes.

## [0.0.3] - 2026-11-19
### Added
- Six more colour themes (Dracula, Nord, Mocha, Matrix Terminal, Sky Light, Rose Light), 15 in total.
- The theme picker moved to the top bar, grouped into Dark and Light.
- Complete GitHub guide (`docs/GITHUB-GUIDE.md`): SSH setup, first push, CI, releases, troubleshooting.
- Dependabot configuration, `.gitattributes`, release gate and release notes from this changelog.

## [0.0.2] - 2026-11-17
### Added
- Circuit Lab: wire and run an Arduino Uno (sketch interpreter + electrical model).
- PDF lab reports with student name and registration number (per lab and full portfolio).
- Reset the whole simulator or any single lab.
- Nine themes, About dialog, author and licence information.

## [0.0.1] - 2026-11-16
### Added
- First release: Labs 1-16 simulation, MQTT broker, ML and TinyML labs, DEB / RPM / Windows installers.
